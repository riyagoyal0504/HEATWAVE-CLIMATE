# Climate Intelligence for Heatwave Monitoring (DBMS Mini Project)

A relational-database-driven system for storing heatwave weather data, generating alerts with a trigger, and showing role-based dashboards.

Stack: HTML/CSS/JavaScript frontend, Python Flask backend, SQLite database.
Data: Kaggle dataset "Weather data Indian cities (1990 to 2022)" (CC0).

## Run

    pip3 install flask
    python3 app.py

Then open http://127.0.0.1:5000

Demo logins: admin/admin123, analyst/analyst123, public/public123
The database (heatwave.db) is created automatically on the first run.
